# Redigerbare grunddata
- B-017: direkte redigering uden Redigér/Gem, automatisk anvendelse/gemning. B-018 godkender R-002 ændringsvisning/filter og R-003 Fortryd/Gentag i aktiv session + standardcelle/række. B-019 afviser R-005 profiler; data/indtastede værdier skal huskes i samme browser/computer. Valgt JSON i localStorage. R-004 (tastatur/søgning/Excel-indsætning) er forklaret, ikke godkendt. Se docs/BESLUTNINGER.md og docs/REDIGERINGSFORSLAG.md.
- auto-edit.ts opdaterer aktiv DataState ved gyldige ændringer og returnerer gemmehandling. Ugyldige materialer/diagrammer bevarer aktiv tilstand. edit-review.ts giver ændringsvisning; originale diagrammarkeringer bruger Python round(...,6), ikke beregningstolerance. edit-session.ts håndterer historik med præcise kopier.
- session-storage.ts og saved-editor.ts gemmer samlet snapshot med data + values gennem getItem/setItem. Tests bruger isoleret lager. React og faktisk window.localStorage mangler tilkobling. Ingen profiler/server. Ugyldigt lager overskrives ikke. Gemmefejl returneres; aktive ændringer bevares og kan gemmes igen.
- Nye komplette snapshots genåbnes præcist, også bevidst null i maskekrav. Gamle JSON-loaders med standard-backfill bevares særskilt. Defaults ændres ikke. Historik genstartes ved reload; værdier genindlæses.
- editing.ts normaliserer materialer, diagrammer, VejDim og indstillinger. Tom diagramcelle er null, ikke 0/interpolation. VejDim supplerer standardrækker; dubletter beholdes mens opslag bruger sidste. Standardidentisk VejDim gemning har legacy-delete; browseradapter gemmer samlet snapshot så andre sektioner bevares.
- Python Unicode-casefold og afrunding bevares. Referenceværktøjer bruger originale AST-funktioner i isoleret kildearkiv. review-cases.json indeholder otte fastlåste cases før markørimplementation. Oprindelige forventninger må ikke omskrives.
- Kontrolstatus/afgrænsning: docs/REDIGERING_OG_LAGRING.md. Generelle rammer: `mem:core`. Kontroller: `mem:task_completion`.
