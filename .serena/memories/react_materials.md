# React-materialeudkast
- React 19.3 / Vite 8.3 / Tailwind 4.3 / TypeScript 7 + officielle shadcn new-york Button/Input/Badge er opsat. package-lock.json er låst. npm run build; npm run preview giver http://127.0.0.1:5174/. Dev er port5173 (andet browserlager).
- B-020: brugeren har GODKENDT at arbejde videre med mørkegrøn topbjælke, lyse tabeller og gule ændringsmarkeringer. Citat: Ja, arbejd videre med denne retning. Firmalogo, navigation og opbygningsfigurer ikke dermed godkendt. R-004 stadig uafklaret. B-017/018/019 gælder fortsat.
- src/ui/App.tsx er første fungerende side, Materialer. To oprindelige grupper, alle fem felter og oprindelige grænser/trin/hjælpetekster. Direkte celler afsluttes ved blur/Enter og automatisk gemmes via SavedEditor + faktisk localStorage. Fortryd/Gentag, standardcelle/række, reset, tilføj/slet, ændringsfilter og phi-advarsel er tilkoblet. Cellernes tekst er midlertidig indtastning, ikke en Anvend/Gem-kladde. Gyldig ny række kræver navn+phi.
- Gemmefejl bevarer aktive data og vises korrekt. Ugyldige lagrede data overskrives ikke. Storage-event fra anden fane låser udkastets redigering, til brugeren genindlæser; ingen merge.
- 2614 motor-/datatests + 11 Playwright-browserforløb. Build og typecheck dækker både Node-engine/report og Vite UI i separat tsconfig.app.json. Chromium desktop/mobil inspiceret. CI Windows/Linux inkluderer build + Chromium tests.
- Materialer er IKKE endnu tilkoblet Brugerdefineret-lagvalg/navigation; manglende materialer, produktnulstilling FUND-001, valgrækkefølge, andre tabeller/CSV/fuld rapportpipeline udestår. Se docs/MATERIALEUDKAST.md for præcis afgrænsning. Ingen ændring af engine eller originale referenceforventninger i UI-leverancen.
- Næste trin: diagram-/VejDim-editor og dimensioneringsformularer i godkendt designretning. Ingen godkendelse til Excel-indsætning/søgning eller ændrede beregningsregler.
